MAHENDRA MUSIC - शुरुआती Android प्रोजेक्ट

इस ZIP में:
- एक WebView आधारित Android ऐप का शुरुआती प्रोजेक्ट
- गानों/ऑडियो के लिए Internet Archive की सार्वजनिक मेटाडेटा सर्च
- जहाँ सीधे ऑडियो फ़ाइल का लिंक मिलता है, वहाँ प्ले और डाउनलोड विकल्प

ज़रूरी सीमाएँ:
- यह हर गाना/हर वेबसाइट नहीं खोज सकता।
- किसी आइटम की डाउनलोड अनुमति उसकी लाइसेंस/शर्तों पर निर्भर करती है। डाउनलोड से पहले स्रोत की शर्तें जाँचें।
- यह ZIP अभी APK नहीं है; इसे Android build सेवा या Android Studio से build करना होगा।
- Android project को build करने के लिए Gradle/Android SDK चाहिए। केवल फोन से करना हो तो किसी भरोसेमंद cloud build workflow की जरूरत होगी।

मोबाइल पर आसान अगला कदम:
1. ZIP को डाउनलोड करके extract करें।
2. GitHub पर नया repository बनाकर इसकी फ़ाइलें upload करें।
3. GitHub Actions/विश्वसनीय Android cloud build workflow से APK build करें, या किसी Android developer से build करवाएँ।
4. APK इंस्टॉल करने से पहले केवल अपने भरोसे के स्रोत से बनी फ़ाइल इस्तेमाल करें।

यह एक शुरुआती prototype है, production-ready app नहीं। इसमें अभी कोई API key, account login, या universal music source शामिल नहीं है।
